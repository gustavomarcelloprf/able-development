# Planejamento

Documentos de planejamento do site, trazidos do primeiro projeto em Next.js (jul–ago/2026). Aquele código era só o esqueleto inicial e foi substituído pela landing estática de `landing/`.

Estes documentos ficam como histórico das decisões:

- `able-development-plano-arquitetura.md` e `-v2.md`: o plano técnico do site em Next.js e a auditoria desse plano.
- `able-development-arquitetura-conteudo.md`: o esqueleto de informação do site.
- `able-development-conceito-foco.md`: o conceito "Foco", que substituiu o Selo de Aferição.
- `able-development-referencias-motion.md`: a análise das referências de motion.
- `referencias-icone/`: imagens de referência usadas na busca do símbolo. Ficam só na máquina e não vão para o git, porque são trabalhos de terceiros.

A identidade atual está em `docs/` e em `Able Development Design System/`. A landing é o guia de design.
