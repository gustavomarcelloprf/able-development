Botão de ação; use um primário por vista, nomeado pelo efeito ("Publicar projeto", "Arquivar"), e secundário para cancelar/voltar.
```jsx
<Button>Publicar projeto</Button>
<Button variant="secondary">Cancelar</Button>
<Button tone="dark">Repetir</Button>
```
Props: variant primary|secondary; tone light|dark (sobre grafite); disabled. Sem ícone, sem tamanho pequeno: 44 px de alvo sempre.
